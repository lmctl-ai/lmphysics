# Schema v0

Generated by `scripts/gen-schema.py` from the `method(r, "Type", "name", {params}, "Ret", ...)` and
`getter(r, "Type", "col")` registrations in `cpp/main.cpp`, written to `schema/lmphysics.dsl.json`
and embedded in the binary. `test.sh` diffs it against `lmscript --dsl-signatures`. Context
variable: `phys` of type `Phys`. Primitive types only (`int`, `float`, `string`, `bool`) plus the
object types `System`, `Body`, `Joint`.

Conventions
- SI units, right-handed, gravity `(0,0,-9.81)`, angles in radians.
- Every setter returns its receiver so calls chain. Bodies and joints are owned by their system;
  objects are never freed during a run (a script has bounded lifetime).
- Names are unique across bodies and joints of one system; `record(name, columns)` finds either.
- Bodies keep the pose they have when a joint is created: set `pos`/`rot_axis` *before* joints.
  Joint points and axes are in world coordinates at creation.
- `Joint.angle()` is the unwrapped rotation of body B about the joint axis since creation (tracked
  once per step, so keep |omega| dt < pi). Motors are built with the bodies swapped internally
  because Chrono turns body 1 against body 2; the schema still means "B rotates relative to A".
- `Joint.reaction_*` are the force on B in world coordinates.
- `record` must precede the first `step`/`run`; the CSV gets a row at t=0 and one per step.
- Contact materials: `"default"` exists; `material()` creates NSC or SMC materials by system kind;
  `stiffness()` (SMC only) sets Young's modulus and Poisson ratio (default 2e7 Pa, 0.3).
- `Body.collide(material)` attaches the body's shape as collision shape; a body without shape
  (`ground`) cannot collide. `floor(name, material)` is a fixed 200x200x2 slab with its top at z = 0.
- Cylinder axis is the local y axis, for the inertia and the collision shape. (Chrono 9's
  `ChCollisionShapeCylinder` runs along z; the host adds it rotated -90 degrees about x. Before that fix
  a cylinder collided as if standing upright while spinning like one lying down.)
- Materials are fixed once a body uses them: `material()`/`stiffness()` on a material already attached by
  `collide()`/`floor()` is an error (Chrono shapes hold the old object, so a redefinition would be silently ignored).
- A step is an error (exit 3) when any body state becomes NaN/inf, when a direct solver's factorization
  fails (Chrono only prints "Solver setup failed" and continues), or when an NSC system has contacts
  while a linear solver (sparse_lu/sparse_qr/minres, e.g. preset by `hht`) is active (Chrono returns garbage:
  a ball on the floor ended at z = 88 km).

Counts: `Phys` 4, `System` 29, `Body` 22, `Joint` 7 distinct method names (see the JSON).
